# run5 下发指令 vs 设备 self-use 偏差归因（不带电价）

> 状态：分析记录，非设计变更。仅回答「策略主动下发的功率指令，比设备自用该给的功率偏在哪、偏多少」，不折价。
> 数据源：`outputs/local_mock_20261016_run5/audit.csv`（1008 行，三站各 336 轮，30 分钟采样）。
> 分析脚本：`scripts/analysis/analyze_run5_dispatch_deviation.py`。
> 关联：[run5 赛后利润归因](../experiments/run5_profit_attribution.md)（若存在）、[HOLD_SEMANTICS_DESIGN.md](./HOLD_SEMANTICS_DESIGN.md)。

## 1. 背景

run5（dashboard idx8）settled saving 三站 −6.33 €（−6.75%）：site1 +1.63（+12.8%）、site2 −0.91（−14.2%）、site3 −7.05（−9.4%）。此前「钱去哪」分析已给出金额层面的结论：site2 基线自给自足(0/0)却被我们进口 +3.43€、出口 +1.93€；site3 多进口 +10.22€、多出口 +2.52€；site1 净 +1.37€。

本文回答**机制**问题：逐轮比对「下发指令的功率」与「设备自用该给的功率」，定位偏差发生在哪类轮次。

## 2. 方法

### 2.1 self-use 参考（设备留在 `self_consumption` 模式）

与 `contest_replay.self_use` 同口径，并按 `observed_soc` 做 SOC 限幅：

- 余量（`pv > load`）：充电 `min(max_power, 余量, SOC 余量上限)`，其余出口；
- 缺口（`load > pv`）：放电 `min(max_power, 缺口, SOC 可用量)`，其余进口。

### 2.2 关键信号 `target_w` 的方向语义

`target_w` 是 `number/…/power_control` 的设定值，随 `command_flow` 方向语义不同（易混，务必区分）：

| `command_flow` | `target_w` 含义 |
|---|---|
| `charge` | 充电功率（≈ `planned_power_w`） |
| `discharge` | **电网出口目标**（`= pv + 放电 − load`，为正） |

因此「满功率外送套利」只对 **discharge 轮次** 用 `target_w > 50 W` 判：`target_w ≈ 0` 的 discharge 是自用（覆盖缺口），`target_w ≈ 5000` 的 discharge 是向电网满功率倒电。

### 2.3 逐轮偏差定义

每轮计算我方电网净流 vs self-use 电网净流之差，并归类：

- `余量 + discharge`：自用本该**充电**，我方却**放电外送**（套利外送，偏差 < 0）。
- `缺口 + charge`：自用本该**放电**，我方却**充电**（购电充电，偏差 > 0）。
- `余量 + charge`：`pw` 小于余量 = 少充（余量外送）；`pw` 大于余量 = 多充（购电）。
- `缺口 + discharge`：`pw` 小于缺口 = 少放（负载裸奔进口）；`pw` 大于缺口 = 多放（外送）。

## 3. 结果

| 行为 | site1 | site2 | site3 |
|---|---:|---:|---:|
| 购电充电（charge 功率 > PV 余量，从电网进口填电池） | **0 轮** | **27 轮 / 63.4 kWh** | 10 轮 / 10.1 kWh |
| 满功率外送（discharge 且 `target_w > 50 W`，向电网倒电） | **42 轮 / 102.7 kWh** | 26 轮 / 55.9 kWh | 16 轮 / 30.9 kWh |
| 自用放电（`target_w ≈ 0`，覆盖缺口） | 136 轮 | 125 轮 | 125 轮 |
| idle/hold（交给设备自用） | 129 轮 | 65 轮 | 105 轮 |
| charge / discharge 轮数合计 | 29 / 178 | 120 / 151 | 90 / 141 |

购电充电集中在 site2 的 11:30–15:30：PV 只剩 ~60–350 W、余量仅 +50~240 W，MILP 仍以 **满功率 5000 W 充电**，每轮从电网进口 ~4800 W 填电池（SOC 14%→49%）。这是主动「买电填电池」套利，不是自用。

## 4. 与 run5 盈亏的吻合

- **site1（净 +1.37 €，赢）**：只外送、零购电——倒出去的是白天光伏充进去的「免费电」，满功率外送 102.7 kWh 全是净出口收益。
- **site2（净 −1.50 €，输）**：既购电充电（63.4 kWh）又外送（55.9 kWh）——买入→卖出的来回，赚头吃在价差上，效率/损耗再吃掉一部分。
- **site3（净 −7.70 €，输）**：外送 + 购电充电 + 本身就有 ~72.6 kWh 的缺口（self-use 也要进口）；外送把电池倒空后夜间更不够用，二次放大进口。

## 5. 口径提醒（重要）

本文 kWh 用**指令功率 × 0.5 h 重构**，不是 sim 实际计费值。对照 dashboard：

- site2 指令重构购电 63.4 kWh，但 dashboard 实际进口成本仅 3.43 €；按快照进口价 0.294 算只对应 ~11.7 kWh。差距来源二选一或兼有：①中午进口价远低于 0.294（分时电价）；②实际充电功率未达满功率 5000 W。
- 这一差距**只有拿到完整电价序列才能坐实**。故本文只下「行为类型 + 轮次」的确定结论（购电充电 / 满功率外送），**kWh 金额的最终归因留待电价序列**。

## 6. 结论

1. 策略的主动下发**不是自用，而是套利**：两类偏差——**购电充电**（charge 功率超过 PV 余量）与**满功率外送**（discharge 向电网倒电）。
2. 亏损全部来自显式下发轮次（覆盖设备 self-use 反而更差）；idle 轮与基线一致。
3. 后续：下次 mock 每轮落盘 `/api/price`，赛后算理论最大 @15min/@30min 并分解粒度损失。
