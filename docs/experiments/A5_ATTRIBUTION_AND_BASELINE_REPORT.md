# A5 归因报告与同输入基线对比（2026-10-14）

本报告是五个练习站点、每站 168 小时的**离线诊断**；不是官方结算，也不是 F1 参数冻结或 F2 的 100 站正式收益报告。两次回放使用相同 `forecast_data` 哈希、窗口、50% 初始 SOC、0.02 EUR/kWh 内部磨损成本、2 秒求解预算和当前同一版代码；唯一实验变量是成功计划的 idle 执行模式。完整数据及机器可读核对见 `outputs/w1_a5_compare_20261014_1/a5_same_input_comparison.json`。

## 验收项 A5-1：归因报告

逐步 trace 已明确写入 `optimizer_attributed` 和 `attribution`。成功计划下的 charge/discharge、经验证的 zero-flow idle 标为 optimizer-attributed；自用基线、旧口径 self-consumption idle 和失败回退标为 non-optimizer-attributed。每臂汇总两类步数；旧 trace 缺字段时保持 `null`，不把“未知”算成零。

| 策略臂 | 旧自用 idle：优化器 / 非优化器 | 新零流量 idle：优化器 / 非优化器 | fallback 步数（旧 / 新） |
|---|---:|---:|---:|
| 持久化 PV | 329 / 511 | 840 / 0 | 0 / 0 |
| 辐照度 PV | 495 / 345 | 840 / 0 | 0 / 0 |
| 自用基线 | 0 / 840 | 0 / 840 | 0 / 0 |

这批数据未触发 fallback，因此“fallback 标记正确”由单元测试覆盖，**不能**由此声称在线 fallback 的收益或发生率已验证。

## 验收项 A5-2：旧口径与新零流量口径同输入对比

收益均为相对同一自用基线的“期末库存估值后节省估计”，只用于比较两种 idle 语义。百分比以各站 `K` 总和为分母，不是各站百分比均值。

| 策略臂 | 旧自用 idle | 新零流量 idle | 新减旧 |
|---|---:|---:|---:|
| 持久化 PV | 12.022 EUR / +6.238% | -4.076 EUR / -2.115% | -16.098 EUR / -8.352 百分点 |
| 辐照度 PV | 21.523 EUR / +11.167% | 17.738 EUR / +9.204% | -3.785 EUR / -1.964 百分点 |

两臂均为 5/5 站物理审计通过，分别审计 2,520 行；最大能量和电网残差均 ≤1.78e-15 kWh，成本残差为 0。输入等价由 manifest 比较程序验证；新、旧口径各自的 `summary.json`、站点 trace 和 manifest 保存在 `outputs/w1_a5_compare_self_20261014_1/` 与 `outputs/w1_a5_compare_zero_20261014_1/`。

## 口径边界

- 历史“旧口径”是成功计划 idle 交给设备自用逻辑，不能把这部分收益归因于优化器；新口径是离线模拟的零流量指令。三站硬件验证是另一份证据，不能把本离线回放说成实时硬件执行。
- 练习数据的天气使用历史短波实测作为“可发布天气”的代理，未复现真实天气 API 预测误差、15 分钟瞬态、执行延迟或官方 ledger。
- 本报告完成 A5 的归因与基线对比两个**离线验收项**；F1/F2 均未完成，100 站正式收益数字不得从这里推出。
