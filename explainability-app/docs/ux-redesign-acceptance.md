验收日期：2026-10-14。对象：本仓库 `frontend` 的家庭首页、生活计划、光伏与储能、费用、家庭偏好及原始证据页面。

本轮使用独立本地人工演示数据库和浏览器任务空间。没有用新增页面下发实际 HA 指令；没有上线 AWS 页面，也没有验证真实用户理解效果或官方结算。

## 浏览器端到端

用 ego-browser 对本机 `http://127.0.0.1:8086` 验证：

| 流程 | 实测结果 |
| --- | --- |
| 单家庭首页 | 已显示快照时刻、人工来源、建议功率及真实控制含义；不能实测的电网交换标为缺失 |
| 不足需求 | 电动车需求 100 kWh、3.7 kW、90% 效率、4 h 窗口，显示缺口约 96.31 kWh，不能确认保存 |
| 可行建议 | 同窗口需求 5 kWh，输入电量 5.5556 kWh，建议分配 3.7 与 1.8556 kWh，估计购电费用 €0.6483（界面约 €0.65） |
| 确认与保存 | 评估前没有本地记录；确认后新增一条建议、关闭对话框，页面显示需手动操作 |
| 评估后的可见性 | 结果区自动滚入对话框视野并获得焦点；手机无需猜测结果是否在下方 |
| 偏好与家庭隔离 | 家庭 01 的备用草案保存为 45%；切换家庭 02 仍为默认 20% |
| 语言 | 英语与中文切换成功，`document.lang` 同步；原证据工作台继续提供中文 |
| 原始详情 | 从新界面直接打开原决策，仍呈现事实、来源、费用、能力和执行记录 |
| 真实反事实工作进程 | 页面提交首步充电 0 kW，任务完成，原/替代共 8 行计划，模型费用差为 +€0.811105 |
| 证据返回导航 | 从比较页返回证据总览，三站卡片可用；旧浏览器 smoke 脚本初始地址适配为 `/#/evidence` |

以上反事实费用差属于人工算例的模型结果。新本地计划费用是独立购电估算，未联合计算光伏、电池、家庭容量或多设备需求。

## 布局与视觉检查

1440×1000、1200×850、390×844、360×800 四种视口，每种覆盖首页、计划、光伏、费用、偏好、证据，共 24 组检查。所有检查均无页面水平溢出。

人工视觉复核发现并修正了手机首页说明与插图重叠，以及计划结果藏在长表单下方的问题。最终手机首页采用正常纵向文档流，平板说明与插图使用独立栅格；评估后自动定位结果。主要触控按钮为 44 px，保留键盘焦点和减少动画支持。这是本轮操作和视觉检查，不是完整 WCAG 合规认证。

证据包位于工作区 `output/uiux-europe/`，包含：

- 桌面、手机中英首页以及计划、光伏、费用、偏好截图。
- 1200 px 与 360 px 首页补充截图。
- 手机计划评估、原始证据详情、三站总览、反事实比较截图。
- `browser-layout-checks.json`：24 组布局检查。
- `delivery-receipt.json`：交付文件及校验摘要。
