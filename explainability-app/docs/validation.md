# 验证与证据边界

自动测试覆盖模型守恒和状态边界；浏览器验收覆盖用户在三页中的完整流程。启动和复现命令见 [运行说明](operations.md)。具体本轮执行结果写入 [验收记录](acceptance.md)。

## 自动验收

| 验收项 | 所需证据 |
| --- | --- |
| 不可变决策 | 相同输入产生稳定哈希，重复导入幂等，变更内容返回 409 |
| 记录隔离 | 不同场次、站点可以使用相同策略决策身份，查询结果互不覆盖 |
| 事实解释 | 每条原因引用真实字段；历史过期和功率/SOC 限制有对应证据 |
| 四步人工模型 | 原成本约 €0.5690；首步不充约 €1.380105；差额约 €0.811105 |
| 物理一致性 | 每步功率守恒、能量更新、SOC/功率边界、充放电和购售电互斥 |
| 费用一致性 | 购电－售电＋损耗－期末信用等于净成本，正负差额如实输出 |
| 来源边界 | 真实决策不能借用人工模型；不匹配模型返回能力不可用 |
| 执行关联 | 缺少提交、错误指令或早于提交的观测不能确认；旧回读不确认新提交 |
| 结算边界 | 没有结算记录保持未结算；重复与冲突遵循幂等规则 |
| 工作进程 | 独立进程计算任务，重启后恢复持久化任务；超时与不可行分别处理 |
| 语言边界 | 有限意图返回事实或任务，不支持的问题说明支持范围 |

## 浏览器验收

完成前端生产构建后，启动同源服务，检查三站总览、低价充电详情、满电约束、历史过期说明及替代方案计算。截图和检查输出保存在忽略目录，验收记录注明实际证据路径。

检查每个页面均标明人工演示来源；费用使用 EUR；设备时间、求解、预测、执行和结算状态分别呈现。替代方案计算中有明确状态，完成后两侧计划、费用、SOC 和假设可同时查看。

## 结果不能证明的事项

人工算例通过验证说明反事实计算、证据留档及展示流程可以运行，不能证明真实预测准确、所有站点省钱或官方结算收益。真实模型注册、HA 实际下发与回读闭环、真实时钟对齐和云端部署仍需要对应环境的验收。
